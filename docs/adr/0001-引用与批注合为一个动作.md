# 引用和批注合为一个动作，用「有没有写意见」来区分

在聊天里选中一段原文后只有一个动作：把它加进待发，每段下面可以附一条意见，也可以不写。没写意见的就是引用，写了意见的就是批注。没有像 Claude、Alma 那样做成两个按钮，原因是这样用户选中时不用先判断这段拿来干什么，想说话再补一句就行；Codex 也是这么做的，它的批注框提示语就是「Add an optional comment…」。

## Considered Options

- **两个独立功能**（Claude、Alma 的做法）：概念分得更清楚。但界面上要有两个入口、两套规则，而且「先引用、再补一句意见」时必须先选对按钮。没有采用。
