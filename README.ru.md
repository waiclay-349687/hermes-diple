# Diple — выделяйте и комментируйте фрагменты чата для ИИ (плагин Hermes Desktop)

Выделите фрагмент в беседе Hermes Desktop, при желании напишите к нему комментарий и отправьте пачку таких фрагментов со следующим сообщением; ИИ ответит на каждый комментарий по очереди, а вы сможете переходить между каждым ответом и его фрагментом.

> **О названии.** *Diple* (›) — знак, которым древнегреческие писцы на полях связывали строку с комментарием к ней, предок кавычек. Китайское название 圈批 означает «отметить и прокомментировать».

> **Неофициальный.** Это плагин сообщества. Его не создавали, не проверяли и не поддерживают Nous Research или проект Hermes Agent.

## Возможности

- **Пометка выделения** — выделите текст в любом сообщении чата, и как только вы отпустите мышь, кнопка **Пометить** появится чуть правее и ниже этой точки, прямо у указателя (или нажмите <kbd>⌘⇧E</kbd>). Она работает, даже если приложение через мгновение снимет выделение. Фрагмент помнит своё происхождение: какой сеанс, какое сообщение, кто это сказал.
- **Выделение или комментарий** — каждый добавленный фрагмент — это *пометка*. Напишите к нему комментарий — и это *комментарий* (ИИ обязан на него ответить); оставьте пустым — и это *выделение* (только фоновый материал).
- **Комментарий на месте** — небольшой редактор открывается там, где была кнопка, под фрагментом (над ним, если снизу нет места): сверху фрагмент (с отрисовкой Markdown), ниже поле комментария, внизу **Сохранить** и **Сохранить и отправить**, а также кнопка-значок, чтобы заменить фрагмент текущим выделением.
- **Булавки на оригинале** — помеченный текст подсвечивается (комментарии ещё и подчёркиваются) и получает пронумерованную булавку в правом верхнем углу. Наведите на булавку — появится карточка с тремя кнопками: **Изменить** (у выделения — **Добавить комментарий**), **Копировать** и **Удалить**; у отправленной пометки есть только **Копировать**.
- **Полоса над полем ввода** — сохранённые пометки ждут там, по сеансам, в виде пронумерованных чипов, пока вы не отправите их. Щелчок по чипу возвращает к фрагменту; можно удалить, очистить всё (с отменой) или посмотреть предпросмотр; список переживает перезагрузку.
- **Отправить N ▾** — отправьте вместе со следующим сообщением или нажмите **Отправить N**, чтобы отправить только пометки. В меню ▾ есть **Отправить сейчас** и **Копировать для ИИ** (Markdown, ничего не отправляется).
- **Метки ответов** — ИИ отмечает каждый абзац, который отвечает на комментарий; приложение показывает его как маленький чип «↩ Комментарий 2», который возвращает к фрагменту.
- **Уведомление о пропущенном ответе** — если ответ пропускает комментарий, вам об этом сообщат («На комментарий 2 нет ответа»), и его можно одним щелчком вернуть в список к отправке.
- **Спокойный переход в обе стороны** — при возврате к фрагменту страница прокручивается, только если он за пределами экрана, и фрагмент остаётся выделенным, без мигания.
- **Очередь, пока ИИ занят** — пока ИИ ещё отвечает, «Отправить после ответа» ставит пакет в очередь и отправляет его, когда ход завершится.
- **Предпросмотр перед отправкой** — увидьте, что именно покажет пузырь чата и что получит ИИ, с оценкой размера относительно лимитов контекста хоста.

Интерфейс плагина доступен на всех языках Hermes Desktop: **English, 简体中文, 繁體中文, 日本語, العربية, Русский, Français, Deutsch и Español** (арабский — справа налево). По умолчанию он следует языку приложения; язык можно также выбрать в настройках плагина. Инструкции для ИИ остаются китайскими для двух китайских интерфейсов и английскими для всех остальных языков.

## Установка

У плагина две половины: плагин для рабочего стола (`plugin.js`) и небольшой бэкенд на Python (`plugins/diple/`). Нужны обе. В командах ниже `~/.hermes` — ваш домашний каталог Hermes; для именованного профиля используйте `~/.hermes/profiles/<имя>`.

### Вариант А: скачать выпуск

1. Скачайте `plugin.js`, `plugin.js.sha256`, `diple-python-0.2.0.zip` и `diple-python-0.2.0.zip.sha256` из [последнего выпуска](https://github.com/waiclay-349687/hermes-diple/releases) и проверьте их:

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-python-0.2.0.zip.sha256
   ```

2. Разложите их по местам:

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple/plugin.js
   unzip -o diple-python-0.2.0.zip -d ~/.hermes/plugins/
   ```

3. Включите бэкенд и перезапустите Hermes Desktop:

   ```bash
   hermes plugins enable diple
   ```

### Вариант Б: из исходников

Нужен Node.js 22 или новее.

```bash
git clone https://github.com/waiclay-349687/hermes-diple.git
cd hermes-diple
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple
```

`scripts/install.mjs` собирает `plugin.js` и копирует обе половины в домашний каталог Hermes, указанный в `--home` (сам он каталог никогда не угадывает). Затем перезапустите Hermes Desktop: половина на Python загружается только при запуске приложения.

## Использование

1. Выделите текст в сообщении чата и нажмите **Пометить** рядом с указателем (или <kbd>⌘⇧E</kbd>). Под выделением откроется редактор.
2. При желании напишите комментарий и нажмите <kbd>Enter</kbd> или **Сохранить**; пустой комментарий сохраняет выделение. Пометка получает пронумерованную булавку и чип над полем ввода. Добавляйте сколько угодно — из этого или других сеансов.
3. Напишите сообщение и отправьте как обычно или нажмите **Отправить N** (или <kbd>⌘⇧↩</kbd>), чтобы отправить только пометки. Строка-квитанция под сообщением («Приложено: 3 пометки · Посмотреть, что получил ИИ») показывает, что ушло.
4. В ответе нажмите чип «↩ Комментарий n», чтобы вернуться к его фрагменту. Если комментарий пропущен, нажмите **Вернуть** в уведомлении.

**Копировать** в карточке булавки копирует текст выделения, а комментарий — в Markdown: фрагмент цитатой (`> ` перед каждой строкой), пустая строка, затем ваш комментарий — тот же формат, что у **Копировать как Markdown** в «Пометках этого сеанса». Чтобы превратить комментарий обратно в выделение, очистите комментарий и сохраните.

Пока ИИ отвечает, <kbd>Enter</kbd> направляет текущий ход, и пометки никогда не уходят вместе с таким сообщением; используйте **Отправить после ответа**.

### Сочетания клавиш

| Действие | По умолчанию | Примечания |
| --- | --- | --- |
| Добавить выделенное в список к отправке | <kbd>⌘⇧E</kbd> | Переназначается в настройках сочетаний клавиш приложения |
| Отправить список | <kbd>⌘⇧↩</kbd> | Переназначается |
| Отправить из полосы | <kbd>⌘↩</kbd> | Когда фокус в полосе над полем ввода |

Рабочие элементы (кнопка, редактор, булавки, полоса, меню) не показывают эти клавиши; они перечислены на странице настроек плагина.

В Windows и Linux <kbd>⌘</kbd> — это <kbd>Ctrl</kbd>. В палитре команд (<kbd>⌘K</kbd>) есть также «Добавить в список к отправке», «Diple: Отправить пометки», «Diple: Предпросмотр того, что получит ИИ», «Diple: Пометки этого сеанса» и «Diple: Настройки» (на языке интерфейса).

## Настройки

Откройте их из палитры команд («Diple: Настройки») или из настроек приложения.

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Включить Diple | вкл. | Главный переключатель. Выключение останавливает сочетания клавиш, список, подсветку добавленных фрагментов и работу с маркерами; данные сохраняются. |
| Показывать панель при выделении | вкл. | Кнопка **Пометить** рядом с выделением. Если выключено: <kbd>⌘⇧E</kbd> или палитра команд. |
| Язык | Как в приложении | Как в приложении или один из девяти языков, каждый под собственным названием. Влияет на интерфейс плагина; инструкции для ИИ — на китайском для 简体中文 / 繁體中文 и на английском в остальных случаях. |
| Тихий режим: только булавки на оригинале | выкл. | Помеченные фрагменты не подсвечиваются и не подчёркиваются, рядом только нумерованная булавка. |
| Оставлять отметки после отправки | вкл. | Отправленные пометки остаются на оригинале бледной отметкой, а «есть ответ» / «без ответа» видно на булавке. |
| Сочетания клавиш | — | Открывает настройки сочетаний клавиш приложения, чтобы переназначить два действия. |
| Сбросить настройки | — | Возвращает значения по умолчанию (язык сохраняется). |

## Как это работает

### Что получает ИИ

Сообщение в чате остаётся коротким: ваш текст, затем по строке на пометку (номер, происхождение, первые ~40 символов, ваш комментарий) и последняя строка `@diple:<id пачки>`. Эта строка — ссылка на контекст Hermes: при отправке хода бэкенд плагина разворачивает её в **полную версию** — полный текст каждой пометки, её происхождение, говорящего и комментарий, а также короткие правила ответа (ответить на каждый комментарий; выделения — только фон). Из одного фрагмента длиннее 4000 символов остаются первые и последние 1500. Нажмите **Предпросмотр** перед отправкой или **Посмотреть, что получил ИИ** после неё, чтобы увидеть обе версии.

### Маркеры ответа

Правила ответа просят ИИ ставить маркер вроде `::ann{b="<id пачки>" n="1,3"}` перед каждым абзацем, отвечающим на комментарии 1 и 3. Hermes Desktop отрисовывает такие директивы; плагин показывает их как значки «↩ Комментарий 1, 3» и проверяет, какие комментарии остались без маркера. Маркеры внутри кода игнорируются.

### Где хранятся данные

- Список к отправке и состояние отправки: хранилище плагинов Hermes Desktop (локальное хранилище приложения, ключи с префиксом `hermes.plugin.diple.`).
- Отправленные пачки (нужны, чтобы разворачивать ссылки `@diple:` и показывать, что получил ИИ): SQLite в `~/.hermes/plugin-data/diple/data.db`.

Проектные решения записаны в [docs/adr](docs/adr/README.md), общая структура — в [docs/architecture.md](docs/architecture.md).

## Конфиденциальность

Всё остаётся на вашем компьютере. Плагин сам не делает сетевых запросов, не собирает телеметрию и ничего не хранит вне домашнего каталога Hermes и локального хранилища приложения. Пометки попадают к поставщику модели только в составе отправленного вами сообщения — точно так же, как набранный вами текст.

## Известные ограничения

Основные (полный список с причинами — в [docs/known-limitations.md](docs/known-limitations.md)):

- Если два окна в один и тот же момент записывают список к отправке одного сеанса, одна из двух записей может потеряться.
- Пометка, сделанная, пока сеанс занят, проверяется по ходу, из которого она взята; если установить это нельзя, она остаётся «непроверенной», а не угадывается.
- После того как приложение сменит id сеанса (например, после сжатия контекста), повторное развёртывание старой ссылки `@diple:` в новом сеансе отклоняется.
- Пункта в контекстном меню пока нет: Hermes Desktop не даёт плагинам точки расширения контекстного меню.

## Совместимость

Проверено с Hermes Agent **v0.22.5 (2026.9.24)**, коммит `bf0203a` (2026-10-22), на macOS. Нужен Hermes Desktop (одна командная строка не загружает плагины рабочего стола). Другие версии могут работать, но не проверялись; пожалуйста, сообщите о результатах.

## Чем отличается

В отобранном каталоге есть похожий плагин рабочего стола **quote-ask** (`hermes plugins info quote-ask`): выделенный текст попадает в поле ввода как цитата Markdown. Он лёгкий и не хранит состояния. Diple предназначен для разбора длинного ответа: хранит список к отправке между отправками, даёт каждому комментарию номер, на который ИИ обязан ответить, проверяет пропущенные ответы, связывает ответы и фрагменты в обе стороны и отправляет полный текст через ссылку на контекст, оставляя сообщение в чате коротким. Diple использует доработанный конвертер «выделение → Markdown» из quote-ask (MIT, см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)). Id плагинов различаются (`quote-ask` и `diple`), поэтому их можно установить одновременно.
