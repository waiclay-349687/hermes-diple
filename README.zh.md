# 圈批（Diple）— 在对话里划线、写批注，交给 AI 逐条回应（Hermes 桌面端插件）

在 Hermes 桌面端的对话里划出一段文字，可以附一条意见，攒成一批随下一条消息发出；AI 会逐条回应每一条意见，你可以在回答和原文之间来回跳转。

> **名字的来历。** Diple（›）是古希腊抄本页边的标记，用来指向一行的注解，也是引号的前身；圈批 = 圈（划线）+ 批（批注）。

> **非官方插件。** 这是社区插件，不是 Nous Research 或 Hermes Agent 项目制作、审核或支持的。

## 功能

- **选中即标注**：在任意一条聊天消息里选中文字，松开鼠标后，「标注」按钮立刻出现在松手处的右下方，紧挨着光标（也可以按 <kbd>⌘⇧E</kbd>）。即使 app 随后清掉了选区，按钮照样能用。标注会记住出处：哪个会话、哪条消息、谁说的。
- **划线与批注**：加进来的每一段都是一条**标注**。写了意见的是**批注**（AI 必须回应），没写的是**划线**（只作背景材料）。
- **在原文下写意见**：小浮层在按钮原来的位置打开，也就是原文下方（下方放不下时翻到上方）。上面是原文（Markdown 已渲染），下面是意见框，底部是「保存」「保存并发送」两个按钮，另有一个图标按钮「用当前选区替换原文」。
- **原文上的图钉**：标注过的原文加底色（批注另加下划线），右上角钉一个编号图钉。鼠标停在图钉上，浮出一张卡片，有三个按钮：「编辑」（划线是「写意见」）、「复制」「删除」；已发送的只有「复制」。
- **输入框上方的胶囊条**：保存过的标注按会话排成编号胶囊，等你发送。点胶囊回到原文；可以删除、全部清空（可撤销）、预览；重新加载后还在。
- **「发送 N 条 ▾」**：随下一条消息一起发出，或者点「发送 N 条」只发标注。▾ 菜单里有「直接发送」和「复制给 AI」（Markdown，什么都不发）。
- **回应标记**：AI 在回应某条批注的段落前写一个标记，界面上显示成「↩ 批注 2」这样的小标签，点一下跳回原文。
- **漏答提示**：回答漏掉了某条批注时会提示（「批注 2 没有回应」），一键「放回待发」。
- **跳回原文不闪**：原文不在屏幕上才滚动，到达后保持加深，不闪烁。
- **忙碌时排队**：AI 还在回答时，用「回答完后发送」把这批标注排队，这一轮结束后自动发出。
- **发送前预览**：看清对话气泡会显示什么、AI 会收到什么，并按宿主的上下文上限估算大小。

插件界面支持 Hermes 桌面端的全部语言：**English、简体中文、繁體中文、日本語、العربية、Русский、Français、Deutsch、Español**（阿拉伯语从右到左显示）。默认跟随 app 的语言，也可以在插件设置里单独指定。发给 AI 的说明文字在两种中文界面下用中文，其他语言一律用英文。

## 安装

插件分两半：桌面端插件（`plugin.js`）和一个小的 Python 后端（`plugins/diple/`），两者都要装。下面命令里的 `~/.hermes` 是你的 Hermes 主目录；如果用的是具名 profile，换成 `~/.hermes/profiles/<名字>`。

### 方式 A：下载 release

1. 从[最新 release](https://github.com/waiclay-349687/hermes-diple/releases) 下载 `plugin.js`、`plugin.js.sha256`、`diple-python-0.2.0.zip` 和 `diple-python-0.2.0.zip.sha256`，然后校验：

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-python-0.2.0.zip.sha256
   ```

2. 放到对应位置：

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple/plugin.js
   unzip -o diple-python-0.2.0.zip -d ~/.hermes/plugins/
   ```

3. 启用后端，然后重启 Hermes 桌面端：

   ```bash
   hermes plugins enable diple
   ```

### 方式 B：从源码安装

需要 Node.js 22 或更新版本。

```bash
git clone https://github.com/waiclay-349687/hermes-diple.git
cd hermes-diple
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple
```

`scripts/install.mjs` 会构建 `plugin.js`，并把两半复制到 `--home` 指定的 Hermes 主目录（它从不自己猜目录）。装完重启 Hermes 桌面端：Python 部分只在 app 启动时加载。

## 用法

1. 在聊天消息里选中文字，点光标旁的「标注」（或按 <kbd>⌘⇧E</kbd>），编辑浮层在选区下方打开。
2. 需要的话写一句意见，按 <kbd>Enter</kbd> 或「保存」；意见为空就存成划线。这一条会在原文上钉一个编号图钉，并在输入框上方出现一个胶囊。可以从当前会话或其他会话加任意多条。
3. 照常输入并发送消息，或者点「发送 N 条」（或按 <kbd>⌘⇧↩</kbd>）只发标注。消息下方的回执行（「已附 3 条标注 · 查看 AI 收到的内容」）说明发出了什么。
4. 在回答里点「↩ 批注 n」标签，跳回对应原文。如果有批注被漏答，在提示上点「放回待发」。

图钉卡片上的「复制」：划线只复制原文；批注复制成 Markdown——原文每行前加 `> `，空一行后是意见，和「本会话标注」里「复制为 Markdown」的格式一样。想把批注变回划线，清空意见再保存即可。

AI 正在回答时按 <kbd>Enter</kbd> 是插话，标注不会跟着插话发出；这时请用「回答完后发送」。

### 快捷键

| 操作 | 默认 | 说明 |
| --- | --- | --- |
| 把选中内容加入待发 | <kbd>⌘⇧E</kbd> | 可在 app 的快捷键设置里改绑 |
| 发送待发列表 | <kbd>⌘⇧↩</kbd> | 可改绑 |
| 在胶囊条里发送 | <kbd>⌘↩</kbd> | 焦点在输入框上方的胶囊条里时 |

使用界面（按钮、浮层、图钉、胶囊条、菜单）上不显示这些键帽，插件的设置页里列出了它们。

Windows 和 Linux 上 <kbd>⌘</kbd> 对应 <kbd>Ctrl</kbd>。命令面板（<kbd>⌘K</kbd>）里也有「加入待发」「圈批：发送待发列表」「圈批：预览 AI 将收到的内容」「圈批：本会话标注」「圈批：设置」（按界面语言显示）。

## 设置

从命令面板（「圈批：设置」）或 app 的设置里打开。

| 设置项 | 默认 | 作用 |
| --- | --- | --- |
| 启用圈批 | 开 | 总开关。关闭后快捷键、待发列表、底纹和回应标记的交互都停用；数据保留。 |
| 选中后显示工具条 | 开 | 选区旁的「标注」按钮。关掉后用 <kbd>⌘⇧E</kbd> 或命令面板。 |
| 界面语言 | 跟随 app | 跟随 app，或九种语言之一（各用自己的名字显示）。影响插件界面；发给 AI 的说明文字在简体中文 / 繁體中文界面下用中文，其他语言用英文。 |
| 安静模式：原文只显示图钉 | 关 | 标注过的原文不加底色和下边线，只在旁边留编号图钉。 |
| 发送后保留标记 | 开 | 已发送的标注在原文上保留淡化的标记，已回应／漏答也标在图钉上。 |
| 快捷键 | — | 打开 app 的快捷键设置，改绑两个操作。 |
| 恢复默认 | — | 恢复默认设置（保留界面语言）。 |

## 工作原理

### AI 收到什么

对话气泡保持简短：你的正文，加上每条标注一行（编号、出处、开头约 40 字、你的意见），最后一行是 `@diple:<批次号>`。这一行是 Hermes 的上下文引用：这一轮发出时，插件后端把它展开成**完整版**——每条标注的完整原文、出处、说话人和意见，以及简短的回应规则（批注要逐条回应，划线只是背景材料）。单段原文超过 4000 字时保留开头和结尾各 1500 字。发送前点**预览**、发送后点**查看 AI 收到的内容**，都能看到两个版本。

### 回应标记

回应规则要求 AI 在回应批注 1 和 3 的段落前写 `::ann{b="<批次号>" n="1,3"}` 这样的标记。Hermes 桌面端会渲染这类指令；插件把它画成「↩ 批注 1, 3」标签，并核对哪些批注没有得到标记。代码里的标记不算。

### 数据存放位置

- 待发列表和发送状态：Hermes 桌面端的插件存储（app 的本地存储，键前缀 `hermes.plugin.diple.`）。
- 已发送的批次（用于展开 `@diple:` 引用、显示 AI 收到的内容）：SQLite，位于 `~/.hermes/plugin-data/diple/data.db`。

设计决定记录在 [docs/adr](docs/adr/README.md)，整体结构见 [docs/architecture.md](docs/architecture.md)。

## 隐私

数据都在你的电脑上。插件自己不发任何网络请求，没有遥测，除了 Hermes 主目录和 app 的本地存储，不往别处写任何东西。标注只会作为你发出的消息的一部分到达模型服务商，和你自己打的字一样。

## 已知限制

主要几条（完整列表和原因见 [docs/known-limitations.md](docs/known-limitations.md)）：

- 两个窗口在同一瞬间写同一个会话的待发列表时，可能丢掉其中一次写入。
- 会话忙碌时加入的标注，会对照产生它的那一轮来验证；确定不了时保持「未验证」，不去猜。
- 宿主轮换会话 id 之后（例如上下文压缩），在新会话里重新展开旧的 `@diple:` 引用会被拒绝。
- 还没有右键菜单入口：Hermes 桌面端没有给插件开放右键菜单扩展点。

## 兼容性

已在 Hermes Agent **v0.22.5 (2026.9.24)**、commit `bf0203a`（2026-10-22）、macOS 上测试。需要 Hermes 桌面端（只有 CLI 不会加载桌面插件）。其他版本可能可用但没有测试过，欢迎反馈。

## 与同类插件的区别

官方精选目录里有一个相关的桌面插件 **quote-ask**（`hermes plugins info quote-ask`）：选中文字后以 Markdown 引用的形式放进输入框，轻量、不保存状态。圈批面向审读长回答：待发列表跨多次发送保留，每条意见带编号、AI 必须回应，会核对漏答，回答和原文双向链接，完整原文通过上下文引用送达而对话气泡保持简短。圈批改编了 quote-ask 的「选区转 Markdown」代码（MIT，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)）。两者插件 id 不同（`quote-ask` 与 `diple`），可以同时安装。
