# Diple — 会話の一節にハイライトやコメントを付けて AI に渡す（Hermes Desktop プラグイン）

Hermes Desktop の会話で一節を選んでハイライトし、必要ならコメントを付け、次のメッセージと一緒にまとめて送ります。AI はコメントに一つずつ答え、回答と元の一節の間を行き来できます。

> **名前の由来。** *diple*（›）は、古代ギリシャの写字生が余白に記した印で、行をその注解に結びつけるもの — 引用符の祖先です。中国語名の 圈批 は「印を付けて批評する」という意味です。

> **非公式。** これはコミュニティ製のプラグインです。Nous Research や Hermes Agent プロジェクトが作成・審査・サポートしているものではありません。

## 機能

- **選択して注釈** — チャットのメッセージでテキストを選択し、マウスを離すと、離した位置のすぐ右下、ポインタの隣に「注釈」ボタンが出ます（<kbd>⌘⇧E</kbd> でも可）。直後にアプリが選択を解除しても、ボタンはそのまま使えます。注釈は出典を覚えています：どのセッションの、どのメッセージの、誰の発言か。
- **ハイライトとコメント** — 追加した箇所はすべて*注釈*です。意見を書けば*コメント*（AI は必ず回答します）、空欄なら*ハイライト*（背景資料のみ）になります。
- **その場で意見を書く** — ボタンがあった位置、つまり原文の下に小さなエディタが開きます（下に収まらないときは上）。上に原文（Markdown を描画）、下に意見欄、下端に「保存」「保存して送信」と、「現在の選択範囲で置き換え」のアイコンボタン。
- **原文のピン** — 注釈した原文には下地が付き（コメントは下線も）、右上に番号付きのピンが付きます。ピンにマウスを置くとカードが出て、ボタンは 3 つ：「編集」（ハイライトでは「意見を書く」）、「コピー」「削除」。送信済みは「コピー」だけです。
- **入力欄の上のストリップ** — 保存した注釈はセッションごとに番号付きのチップとして並び、送信を待ちます。チップをクリックすると原文へ戻ります。削除、すべてクリア（元に戻せます）、プレビューができ、再読み込み後も残ります。
- **「N 件を送信 ▾」** — 次のメッセージと一緒に送るか、「N 件を送信」で注釈だけを送ります。▾ メニューには「今すぐ送信」と「AI 用にコピー」（Markdown、何も送信しません）があります。
- **回答マーカー** — AI はコメントに答える段落の前に印を付け、アプリは「↩ コメント 2」の小さなチップとして表示します。クリックで原文へ戻ります。
- **未回答の通知** — 回答がコメントを飛ばすと知らせ（「コメント 2 に回答がありません」）、ワンクリックで送信待ちに戻せます。
- **ちらつかない位置移動** — 原文へ戻るときは画面外のときだけスクロールし、到着後は強調を保ったまま、点滅しません。
- **回答中はキューへ** — AI がまだ回答中なら「回答後に送信」でまとめてキューに入れ、そのターンが終わると送信します。
- **送信前のプレビュー** — チャットの吹き出しに何が出るか、AI が何を受け取るかを、ホストのコンテキスト上限に対するサイズ見積もりとともに確認できます。

プラグインの UI は Hermes Desktop のすべての言語に対応しています：**English、简体中文、繁體中文、日本語、العربية、Русский、Français、Deutsch、Español**（アラビア語は右から左）。既定ではアプリの言語に合わせ、プラグインの設定で個別に選ぶこともできます。AI に送る指示文は、中国語の二つの UI では中国語、それ以外の言語では英語のままです。

## インストール

プラグインはデスクトッププラグイン（`plugin.js`）と小さな Python バックエンド（`plugins/diple/`）の二つで構成され、両方が必要です。以下のコマンドの `~/.hermes` はあなたの Hermes ホームです。名前付きプロファイルを使う場合は `~/.hermes/profiles/<名前>` に置き換えてください。

### 方法 A：リリースをダウンロード

1. [最新リリース](https://github.com/waiclay-349687/hermes-diple/releases) から `plugin.js`、`plugin.js.sha256`、`diple-python-0.2.0.zip`、`diple-python-0.2.0.zip.sha256` をダウンロードし、検証します：

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-python-0.2.0.zip.sha256
   ```

2. 所定の場所に置きます：

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple/plugin.js
   unzip -o diple-python-0.2.0.zip -d ~/.hermes/plugins/
   ```

3. バックエンドを有効にして Hermes Desktop を再起動します：

   ```bash
   hermes plugins enable diple
   ```

### 方法 B：ソースから

Node.js 22 以降が必要です。

```bash
git clone https://github.com/waiclay-349687/hermes-diple.git
cd hermes-diple
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple
```

`scripts/install.mjs` は `plugin.js` をビルドし、二つの部分を `--home` で指定した Hermes ホームにコピーします（場所を推測することはありません）。その後 Hermes Desktop を再起動してください。Python 側はアプリの起動時にしか読み込まれません。

## 使い方

1. チャットのメッセージでテキストを選択し、ポインタの隣の「注釈」をクリックします（または <kbd>⌘⇧E</kbd>）。選択範囲の下にエディタが開きます。
2. 必要なら意見を書き、<kbd>Enter</kbd> か「保存」を押します。意見が空ならハイライトとして保存されます。原文に番号付きのピンが付き、入力欄の上にチップが出ます。このセッションでも他のセッションでも、いくつでも追加できます。
3. いつもどおりメッセージを書いて送信するか、「N 件を送信」（または <kbd>⌘⇧↩</kbd>）で注釈だけを送ります。メッセージ下の受領行（「注釈 3 件を添付 · AI が受け取った内容を表示」）で、何が送られたかがわかります。
4. 回答の中の「↩ コメント n」チップをクリックすると、その原文へ戻ります。飛ばされたコメントがあれば、通知の「送信待ちに戻す」を使います。

ピンカードの「コピー」：ハイライトは本文だけ、コメントは Markdown でコピーします — 原文の各行の前に `> `、空行、そのあとに意見。「このセッションの注釈」の「Markdown としてコピー」と同じ形式です。コメントをハイライトに戻すには、意見を消して保存します。

AI の回答中に <kbd>Enter</kbd> を押すと現在のターンへの追加指示になり、注釈は追加指示と一緒には送られません。その場合は **回答後に送信** を使ってください。

### ショートカット

| 操作 | 既定 | 備考 |
| --- | --- | --- |
| 選択範囲を送信待ちリストに追加 | <kbd>⌘⇧E</kbd> | アプリのキーボードショートカット設定で変更可能 |
| 送信待ちリストを送信 | <kbd>⌘⇧↩</kbd> | 変更可能 |
| ストリップから送信 | <kbd>⌘↩</kbd> | 入力欄の上のストリップにフォーカスがあるとき |

作業中の画面（ボタン、エディタ、ピン、ストリップ、メニュー）にはこれらのキーキャップを表示しません。プラグインの設定ページに一覧があります。

Windows と Linux では <kbd>⌘</kbd> は <kbd>Ctrl</kbd> です。コマンドパレット（<kbd>⌘K</kbd>）にも「送信待ちに追加」「Diple: 送信待ちの注釈を送信」「Diple: AI が受け取る内容をプレビュー」「Diple: このセッションの注釈」「Diple: 設定」があります（UI の言語で表示されます）。

## 設定

コマンドパレット（「Diple: 設定」）またはアプリの設定から開きます。

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| Diple を有効にする | オン | マスタースイッチ。オフにするとショートカット、リスト、追加した一節の網掛け、マーカーの操作が止まります。データは残ります。 |
| 選択時にツールバーを表示 | オン | 選択範囲の横の「注釈」ボタン。オフのときは <kbd>⌘⇧E</kbd> かコマンドパレットを使います。 |
| 言語 | アプリに合わせる | アプリに合わせる、または九つの言語のいずれか（それぞれ自身の言語名で表示）。プラグインの UI に影響します。AI に送る指示文は 简体中文 / 繁體中文 なら中国語、それ以外は英語です。 |
| 控えめモード：原文にはピンだけ表示 | オフ | 注釈を付けた一節に網掛けや下線を付けず、横に番号付きのピンだけを置きます。 |
| 送信後もマークを残す | オン | 送信済みの注釈は原文に薄いマークを残し、回答済み・未回答をピンに表示します。 |
| ショートカット | — | アプリのキーボードショートカット設定を開き、二つの操作を割り当て直します。 |
| デフォルトに戻す | — | 既定値に戻します（言語は保持）。 |

## 仕組み

### AI が受け取るもの

チャットの吹き出しは短いままです：本文のあとに、注釈一件ごとに一行（番号、出典、冒頭の約 40 文字、コメント）、最後の行が `@diple:<バッチ ID>` です。この行は Hermes のコンテキスト参照で、ターンを送信するとプラグインのバックエンドがそれを **完全版** に展開します — 各注釈の全文、出典、発言者、コメントと、短い応答ルール（コメントにはそれぞれ答える、ハイライトは背景資料のみ）です。4000 文字を超える一節は、先頭と末尾の 1500 文字ずつを残します。送信前の **プレビュー**、送信後の **AI が受け取った内容を表示** で両方の版を確認できます。

### 応答マーカー

応答ルールは、コメント 1 と 3 に答える段落の前に `::ann{b="<バッチ ID>" n="1,3"}` のようなマーカーを書くよう AI に求めます。Hermes Desktop はこのディレクティブを描画し、プラグインはそれを「↩ コメント 1, 3」チップとして表示し、マーカーが付かなかったコメントを回答から探します。コード内のマーカーは無視されます。

### データの保存場所

- 送信待ちリストと送信状態：Hermes Desktop のデスクトッププラグインストレージ（アプリのローカルストレージ、キー接頭辞 `hermes.plugin.diple.`）。
- 送信済みのバッチ（`@diple:` 参照の展開と、AI が受け取った内容の表示に必要）：`~/.hermes/plugin-data/diple/data.db` の SQLite。

設計上の判断は [docs/adr](docs/adr/README.md)、全体構成は [docs/architecture.md](docs/architecture.md) にあります。

## プライバシー

すべてあなたのマシン上に留まります。プラグイン自身はネットワーク通信を行わず、テレメトリもなく、Hermes ホームとアプリのローカルストレージ以外には何も保存しません。注釈がモデル提供元に届くのは、あなたが送ったメッセージの一部としてだけで、入力したテキストと同じ扱いです。

## 既知の制限

主なもの（理由を含む全一覧は [docs/known-limitations.md](docs/known-limitations.md)）：

- 二つのウィンドウが同じセッションの送信待ちリストをまったく同時に書き込むと、一方の書き込みが失われることがあります。
- セッションが応答中に付けた注釈は、それを生んだターンと照合されます。確定できない場合は推測せず「未検証」のままにします。
- ホストがセッション ID を切り替えた後（例：コンテキスト圧縮）、新しいセッションで古い `@diple:` 参照を再展開しようとすると拒否されます。
- 右クリックメニューの項目はまだありません。Hermes Desktop にはプラグイン向けのコンテキストメニュー拡張ポイントがありません。

## 互換性

Hermes Agent **v0.22.5 (2026.9.24)**、コミット `bf0203a`（2026-10-22）、macOS でテストしています。Hermes Desktop が必要です（CLI だけではデスクトッププラグインは読み込まれません）。他のバージョンでも動く可能性はありますが未検証です。結果を報告していただけると助かります。

## 類似プラグインとの違い

厳選カタログには関連するデスクトッププラグイン **quote-ask**（`hermes plugins info quote-ask`）があります：選択したテキストを Markdown の引用として入力欄に入れる、軽量で状態を持たないプラグインです。Diple は長い回答を読み込むためのもので、送信をまたいで送信待ちリストを保持し、AI が必ず答える番号を各コメントに付け、答え漏れを確認し、回答と一節を双方向にリンクし、吹き出しを短く保ったままコンテキスト参照で全文を送ります。Diple は quote-ask の「選択範囲 → Markdown」変換を改変して使っています（MIT、[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 参照）。プラグイン ID が異なる（`quote-ask` と `diple`）ため、両方を同時にインストールできます。
